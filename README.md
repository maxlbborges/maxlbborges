## 🧪 About me

I'm a **Senior QA Automation Engineer** with **7 years in IT** and **5+ years in QA**, most of it spent keeping a large agribusiness ERP stable for **84,000+ active users**.

I build and maintain automation frameworks in **TypeScript/JavaScript**, covering both modern **web ERP modules** and **legacy Delphi desktop apps**, and wire them into CI/CD so problems show up in the pipeline, not in production.

- 🔭 Automation across web, desktop and mobile with **Cypress, Playwright, Selenium and Appium**

## 🚀 Featured project

### 🗺️ Roll20 Map Wall Detector
A computer-vision pipeline that takes **top-down RPG map images** and generates **wall/collision boundaries** for Roll20 Dynamic Lighting.

- **OpenCV** preprocessing + a **U-Net** segmentation model trained on synthetic maps
- Exports detected walls as **Universal VTT** files ready to import into Roll20
- Measured with IoU on synthetic data, with ongoing work on closing the sim-to-real gap on hand-painted maps

`Python` · `OpenCV` · `PyTorch` · `U-Net` · `Computer Vision`
